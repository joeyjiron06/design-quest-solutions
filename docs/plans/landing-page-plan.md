# Landing page Phased Plan

## Phase 0 - Setup

✅ create docs/marketing folder in the root of your project
✅ write down your business details in docs/About.md to describe the business

## Phase 1 - Research & Branding

✅ user research - find user problems voiced on the internet, save to user-voice.md
✅ competitor research - find competitors to the business, save to competitors.md
✅ branding - take user-voice and competitors and come up with a unique angle to the business that defines the branding

## Phase 2 - copywriting

✅ landing page copyright - take branding and generate the sections on the page, title and descriptions for each
✅ for each section, generate copy that helps entice the user to use the product or service, save to landing-page-copy.md

## Phase 3 - Design

1. wireframe the landing page with all the sections using AI
2. find inspiration and build a design.md file to describe your branding
3. generate a tailwind config from shadcn to set your colors
4. generate the hero section
5. build the rest of the sections 1 by 1
